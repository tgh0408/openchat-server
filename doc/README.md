## 使用约定

命令默认在 `openchat-server/` 根目录执行，源码路径也以此为基准。文档内链接可以直接跳转到对应文件。

桌面端、Android 端和管理页面是独立项目。服务端具备某个消息类型或接口，不代表每个客户端都已经接入。

首次部署使用空库初始化流程。`openchat.sql` 包含建表前的删除语句，且没有业务初始数据；注册依赖的 `roomId=1` 全员群需要在开放注册前准备，详见部署说明。

部署文档和测试命令描述操作方式，不代表已经在目标环境完成验证。单元测试、Mock 与真实多实例联调应分别记录结果。
